Маршруты для мотоцикла

Серпантин Хон Ба (1 578 м), перевал Кхань Ле в Далат, прибрежная дорога через Камрань в Винь Хи, полуостров Хон Хео. CB500X с кофрами подходит для многодневного тура, Ninja 400 — для ярких однодневных заездов.

Условия

Нужна категория A и МВУ, стаж от 2 лет. Экипировка (перчатки, мотокуртка) — по запросу.

Вопросы и ответы

Можно ли арендовать мотоцикл для тура по Вьетнаму?
Да. Предупредите о маршруте, установим кофры бесплатно. Возврат — в Нячанге.
Нужен ли опыт?
Да, для мотоциклов с механикой нужен стаж вождения категории A от 2 лет.
