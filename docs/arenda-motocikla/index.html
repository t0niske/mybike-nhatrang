Маршруты для мотоцикла

Серпантин Хон Ба (1 578 м), перевал Кхань Ле в Далат, прибрежная дорога через Камрань в Винь Хи, полуостров Хон Хео. CB500X с кофрами подходит для многодневного тура, Ninja 400 — для ярких однодневных заездов.

Условия

Нужна категория A и МВУ, стаж от 2 лет. Без депозита. Экипировка (перчатки, мотокуртка) — по запросу.
